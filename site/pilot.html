Decisions before the full run

  1. Count resubmissions as one submission. 76 of 166 new-extension PRs "closed by author" were reopened as a fresh PR for the same folder, most within minutes. Counting them as dropout inflates question 6. Proposal: group by author + folder and score the chain by its last PR.
  2. Tighten the duplicate heuristic. The reviewer-link signal (82 PRs) mostly finds real duplicates. The folder-name match (149 PRs) fires on generic lead words like time, text and project. Proposal: only match on a lead word that is rare across folders, then hand-check 30.
  3. Decide whether extension owners count as feedback. Today feedback means Greptile or a Raycast maintainer. Extension owners (association CONTRIBUTOR) also file "changes requested" reviews on PRs to their extension; they're tracked in a separate column for now.
  4. Measure Greptile before and after, not with and without. Inside Feb–Mar the PRs Greptile skipped are mostly the ones opened before it was switched on, so the comparison below is confounded. The full run gives a clean 2024 baseline.
  5. Tag each PR with the stale clock in force. 37 of the 164 auto-closes here ran on the 21 + 14 day clock (Feb 25 – Mar 26, 2025); the rest on 14 + 7. The clock changed six times in the window.
